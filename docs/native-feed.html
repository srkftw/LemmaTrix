Native Feed and federation operation

Feed is a signed native graphical package with a separate account/network owner. Identity holds author seeds; each federation owns its native event service, moderation key, storage and finite policy. Host tools compile/package, configure public pins and supply opaque devices. They do not sign Feed events, choose moderation outcomes, replicate events or maintain a social database. The Campaign009 record identifies the connected local results and qualification limits; this guide describes the implemented interfaces.

Current Network uses the bounded416KiB built-in profile within its existing512KiB physical slot; ordinary packages remain256KiB. Nonzero terminal cancellation and collection name the current request, so a delayed request from the same owner cannot clear or collect a replacement relationship. Explicit owner-wide cancellation uses request0. An accepted idle listener gets its new finite handshake window before the old idle deadline is evaluated.

Finite resources and assurance

A relay has twelve routed channels, enough for six incoming/outgoing pairs; ordinarily one pending listener and one outgoing reserve leave five active pairs. The installed same-image capacity check reached six routes, preserved them through native seventh-client refusal, and reused one released pair. Saturation refusal took 1025.10 seconds in this emulated profile: the retained OS listener can queue an overflow TCP connection until its native setup deadline. This is a substantial admission latency limit. The sixth consumes the last pair; replenishment waits for reclamation. An idle listener starts its finite handshake deadline when a connection is accepted. Actual listener-command failures retire only that listener and retry at most 32 times with bounded backoff (200, 400, 800, 1600, then 3000 work ticks); diagnostic 58 reports this condition. An explicit operator listen can authorize a new retry allowance. Ordinary client disconnects do not consume that operator allowance. During a replacement, an old adapter cleanup event preserves the new creation/listen intent. LISTEN acknowledgements require the current epoch and an outstanding intent; an explicit close clears it. Creation remains bounded by100000workticks until acknowledgement, while an acknowledged idle listener waits for an arrival. Four bulk contexts are separate. Sixteen terminal banks remain bounded by the twelve possible links. Mailbox has four 8 KiB upload stages and one finite writer; Feed has four 16 KiB stages, seven 128 KiB content segments and a 37888-byte committed metadata index. A federation admits at most 64 events/896 KiB and 16 events/256 KiB per author, tightened by selected operator budgets. Quota exhaustion is explicit; there is no infinite history or automatic compaction claim.
