Authority and scope

Where the 23 October application list conflicts with the 28 October MVP specification, follow the MVP specification. Preserve both documents as dated sources rather than rewriting the historical roadmap to look like the current release scope.

LemmaTrixOS is independent of Lemma One hardware. Its canonical guest targets RISC-V; the MVP specifies x86-64 and ARM64 host emulators. This source import adds documentation, not an implementation or evidence of release-gate completion.

Repository documentation format

All first-party README-equivalent documents, specifications, guides, plans, contributor guidance, and other prose documentation shall be actual HTML, not Markdown. Use this page as the documentation entry point. Keep the repository root, .github/, and docs/ free of automatically displayed README files.

See the HTML documentation policy. Open HTML files locally in a browser after cloning; no hosted documentation site or GitHub Pages deployment is implied.

The transcriptions preserve accessible source text, requirement identifiers, and source-page boundaries. They are not byte-identical PDF archives, visual facsimiles, newly approved specifications, or a substitute for missing original source material. Source-specific extraction limitations are recorded on each document.
