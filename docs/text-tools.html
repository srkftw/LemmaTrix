Native Text Tools

Documentation index · Campaign 003, 29 October 2026. Text Tools is an independently compiled, signed and live-installed user application. The shell does not compute its results. This advances the SDK and ordinary native application part of the creator workspace; it is not a complete office editor.

The application owns a 4 KiB ephemeral working buffer. Real focused keyboard input inserts text; Left/Right and Home/End move the caret; Backspace/Delete remove bytes; Page Up/Page Down change the visible portion. Ctrl-U uppercases ASCII letters and Ctrl-L clears the working buffer. The app computes word, byte and LF counts from actual private input. Counts use ASCII whitespace separators; LF is an LF byte count, not Unicode line segmentation. The font currently displays lowercase ASCII with uppercase glyphs. Imported object bytes remain unchanged.

Worker-compatible IPC operation 21 accepts an object handle explicitly granted to this application and streams that object's authorized bytes through Objects. The native app returns actual counts and the payload digest, then shows those results on its own surface. Escape returns to the preserved private input buffer. The IPC request requires the existing trusted management caller; it does not grant the application Launcher administration or permission to disclose its private working buffer. The app has only object.read, display.surface and input.focus rights, exact mask 769. Focus, clipping and trusted approval controls remain compositor/kernel responsibilities.

Build and explicit publisher boundary

./lt app --module Guest.TextTools --entry Guest.TextTools.main --name text-tools --profile 2
./lt release keygen --private build/text-publisher.pem --public build/text-publisher.pub
./lt release create --binary build/live/apps/text-tools.bin --project text-tools --version 1.0.0 \
  --right object.read --right display.surface --right input.focus --profile 2 \
  --sign-key build/text-publisher.pem --source Guest/TextTools.lean --source-base . \
  --output build/text-tools.ltrel
./lt ctl --socket /tmp/lt.sock trust --project text-tools --public build/text-publisher.pub
./lt ctl --socket /tmp/lt.sock inspect build/text-tools.ltrel

Inspect the actual immutable release ID and exact rights before approval. Installation and start use the ordinary guest-authenticated Launcher path and the release slot returned by installation. No development fixture key fallback is present. Key files stay outside the application and exported project graph.
